# 🏃 RunGroop - Running Clubs Web App
Live Demo on AWS EC2: http://18.206.213.74:8080

RunGroop is a Spring Boot web application with a PostgreSQL database that allows users to create, view, and manage running clubs. It’s fully containerized and ready to run using Docker Compose.
<img width="1440" alt="Image" src="https://github.com/user-attachments/assets/1523c8c7-5f0f-4bec-9d5b-5378a2d5c1db" />

## 🛠 Tech Stack

- **Backend**: Java, Spring MVC, Spring Boot
- **Frontend**: Thymeleaf, HTML, CSS
- **Database**: PostgreSQL
- **Build Tools**: Maven

## ⚡ Features

- Create and manage running clubs
- View club details and member information
- Fully responsive web interface
- Docker Compose ready for easy deployment

## 🚀 How to Run Locally

1. git clone https://github.com/DemarisDooley/rungroopSpringMVC.git
2. cd rungroopSpringMVC
3. docker-compose up -d
4. Open http://localhost:8080
